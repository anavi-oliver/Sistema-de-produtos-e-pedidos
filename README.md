# Sistema de produtos e pedidos com API REST

Atividade da disciplina Laboratório de Programação (Ciência da Computação - UEL), Prof. Bruno Bogaz Zarpelão.

Desenvolver um sistema de cadastro de produtos e registro de pedidos de uma loja, formado por três aplicações: uma API REST, uma aplicação web usada pelo dono da loja e um app mobile usado pelos clientes.
